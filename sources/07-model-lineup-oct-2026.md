Notes:
- Opus 5.5: 1M ctx, $4/$20, adaptive thinking always on, default effort medium.
- Sonnet 5.5: 1M ctx, $2/$10, adaptive thinking, default effort high, released 2026-09-28.
- Haiku 4.5: 200K ctx, $1/$5, manual extended thinking, no effort setting. Haiku 5.5 announced as coming "in the coming weeks".
- Fable 5.1: top (Mythos-tier) model, slowest; has extra safeguards in some domains.
- Prefill: not supported on recent Opus models (since 4.6) per third-party migration notes; treat as unavailable on current frontier models.
